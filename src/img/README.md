# Images Directory (`src/img`)

Place your image files here (e.g., `.jpg`, `.jpeg`, `.png`, `.webp`, `.svg`).

### Examples of images you can add:
- `khadija_avatar.jpg` or `khadija.png` - For her portrait in the birthday greeting or candle outro.
- `memories_1.jpg`, `memories_2.jpg` - Photos related to the reflection questions.
- `background.jpg` - An optional custom background image.

### How to use:
You can reference images directly from this folder in `src/img/index.ts` or in any React component:

```ts
import khadijaPhoto from './khadija.jpg';
```
